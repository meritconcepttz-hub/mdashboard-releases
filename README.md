# mDashboard for Mac

Merit Concept's studio dashboard as a Mac app. Part of mSuite by Merit Concept, for internal use.

**Download:** [mDashboard.dmg](https://github.com/meritconcepttz-hub/mdashboard-releases/releases/latest/download/mDashboard.dmg)

Open the disk image and drag mDashboard to Applications. The first time you open it, macOS may say it can't verify the app: open System Settings > Privacy & Security and click Open Anyway. Needs macOS 14 Sonoma or later.

It's the same mDashboard as [dashboard.meritconcept.com](https://dashboard.meritconcept.com), in its own window. Installed copies keep themselves up to date.

This repository holds installers only. The releases are published by `scripts/release.sh` in the private source repository.
